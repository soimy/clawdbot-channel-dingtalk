# v3.6.11 发布说明

本次 patch 版本恢复内联指令（语音 / 回复引用）解析与 OpenClaw 2026.8.x 宿主的兼容性：2026.8 起 `openclaw/plugin-sdk/text-runtime` 子路径被移除，插件改为在 `src/messaging/inline-directives.ts` 本地复现宿主语义，同时保持代码块内指令 tag 的字面量行为。

**最新版本入口**：[`latest.md`](./latest.md)

## 🛠 兼容性与修复

* **内联指令解析兼容 OpenClaw 2026.8.x 宿主**
  * [`PR #597`](https://github.com/soimy/openclaw-channel-dingtalk/pull/597)（by @slzszyt-ux）新增本地 `parseInlineDirectives` 实现，不再引用 2026.8 已移除的 `openclaw/plugin-sdk/text-runtime` 子路径，语音（`audio_as_voice`）与回复（`reply_to` / `reply_to_current`）指令解析在 2026.8 宿主上恢复正常。
  * 代码块（inline / 围栏 / 缩进）内的指令 tag 一律按字面量处理：不被剥离，也不触发语音或回复语义；指令剥离与空白归一化均不再使用失效的原始偏移。
  * `[[...]]` 未匹配任何已知指令时原样返回，不做空白规范化，避免误伤方括号 markdown / LaTeX。

## 📦 兼容性与依赖

* 最低宿主版本维持 `2026.7.1-2`：本功能使用的代码区域辅助 `findCodeRegions` / `isInsideCode` 自该版本起由 `openclaw/plugin-sdk/text-chunking` 公开导出。
* 同一份代码同时兼容 OpenClaw `2026.7.x` 与 `2026.8.x` 宿主线，不新增依赖要求。

> [!IMPORTANT]
> 已将 OpenClaw 宿主升级到 2026.8.x 的用户，请同步升级到本版本或更高版本，以保留语音 / 回复内联指令能力。
